# Tourism Website

A responsive tourism landing page built with HTML and CSS. It showcases travel destinations and featured hotels with a clean, image-focused layout.

## Features

- Destination sections for Dubai, Abu Dhabi and Ras Al Khaimah
- Featured hotels: Nihi Sumba, The Brando and Zarafa Camp
- Custom fonts (Inter and Karma) loaded locally
- Responsive layout built with plain CSS

## Project Structure

```
.
├── index.html
├── styles.css
└── assets
    ├── fonts
    └── images
```

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/bakr0010/tourism.git
   ```
2. Open the folder and double-click `index.html` to view it in your browser.
